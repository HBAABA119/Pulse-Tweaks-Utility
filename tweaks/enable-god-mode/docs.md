# Enable God Mode

## Overview
Creates a "God Mode" folder on your desktop that provides access to all Windows settings and configuration options in one place.

## What it does
- Creates a special folder on the desktop
- Provides access to all Windows Control Panel settings
- Organizes settings by category for easy navigation
- No installation required - just a special folder shortcut

## How it Works
The "God Mode" folder uses the Windows shell namespace with the CLSID `{ED7BA470-8E54-465E-825C-99712043E01C}` which opens the master control panel interface.

## Folder Location
- **Desktop**: `GodMode.{ED7BA470-8E54-465E-825C-99712043E01C}`
- **Alternative locations**: Can be created anywhere (Documents, etc.)

- ✅ All Windows settings in one place

- Safe to use

## Technical Details
This is not actually a "God Mode" in the traditional sense - it's simply a master control panel interface that Microsoft built into Windows. The name comes from the comprehensive access it provides to system settings.
