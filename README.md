<h4>🛠️ Building Pulse Tweaks</h4>

<p>To build Pulse Tweaks you will need the following</p>
<ul>
  <li><b>Node.js</b> v22 or higher</li>
  <li><b>Windows 10/11</b></li>
</ul>

> [!IMPORTANT]

<ol>
  <li>
    <b>Clone the repository:</b>
    <pre><code>git clone https://github.com/HBAABA119/Pulse-Tweaks
cd Pulse-Tweaks</code></pre>
  </li>
  <li>
    <b>Install dependencies:</b>
    <pre><code>npm i</code></pre>
  </li>
  <li>
    <b>Start the app in development mode:</b>
    <pre><code>npm run dev</code></pre>
    <i>This will launch Pulse Tweaks with hot reload for both the Electron main and renderer processes.</i>
  </li>
  <br/>
  <li>
    <b>Build for production:</b>
    <pre><code>npm run build</code></pre>
    <i>This will generate optimized production builds.</i>
  </li>
</ol>
