# Disable Edge QUIC

## Overview
- **ID/URL**: `disable-edge-quic`
- **Description**: Disables Edge QUIC protocol.

## Details

- Disables the QUIC protocol in Microsoft Edge. QUIC is a modern transport protocol that may cause compatibility issues with some network configurations. Disabling it forces Edge to use traditional TCP connections.

!!! tip "Recommended"
    This tweak is recommended.
