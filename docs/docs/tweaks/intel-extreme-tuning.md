# Intel Extreme Tuning

## Overview
- **ID/URL**: `intel-extreme-tuning`
- **Description**: Enables Intel extreme performance tuning for maximum GPU performance.

## Details

- Enables Intel Extreme Tuning for maximum GPU performance. This tweak configures Intel graphics drivers for peak performance by enabling turbo boost, extreme performance levels, and optimized power settings. Ideal for gaming and demanding applications on Intel integrated and dedicated graphics.
