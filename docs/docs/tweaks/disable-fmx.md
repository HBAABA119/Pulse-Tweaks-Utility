# Disable FMX

## Overview
- **ID/URL**: `disable-fmx`
- **Description**: Disables FMX for better gaming performance.

## Details

- Disables the FMX (Financial Management X) platform services. This eliminates unnecessary financial data processing services that run in the background, improving gaming performance by freeing up system resources.

!!! tip "Recommended"
    This tweak is recommended.
