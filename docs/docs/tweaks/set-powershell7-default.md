# Set PowerShell 7 as Default

## Overview
- **ID/URL**: `set-powershell7-default`
- **Description**: Sets PowerShell 7 as the default profile in Windows Terminal (installs PS7 if missing)

## Details

- Sets PowerShell 7 as the default terminal profile in Windows Terminal. If PowerShell 7 is not installed, the tweak will automatically download and install it. This provides a modern, feature-rich command-line experience with improved performance.
