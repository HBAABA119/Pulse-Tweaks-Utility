# NVIDIA Power Mode

## Overview
- **ID/URL**: `nvidia-power-mode`
- **Description**: Optimizes NVIDIA GPU power settings for maximum performance.

## Details

- Optimizes NVIDIA GPU power settings for maximum performance. This tweak sets the GPU power management to prefer maximum performance, preventing the GPU from downclocking to save power. This results in more consistent frame rates and lower latency, especially beneficial for competitive gaming.
