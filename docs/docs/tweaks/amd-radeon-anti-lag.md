# AMD Radeon Anti-Lag

## Overview
- **ID/URL**: `amd-radeon-anti-lag`
- **Description**: Enables AMD Radeon Anti-Lag technology for competitive gaming.

## Details

- Enables AMD Radeon Anti-Lag technology for competitive gaming. Anti-Lag helps reduce input lag by controlling the pace of the CPU to ensure it doesn't get too far ahead of the GPU, reducing the time between your click and the on-screen response.
