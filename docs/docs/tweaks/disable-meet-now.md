# Disable Meet Now

## Overview
- **ID/URL**: `disable-meet-now`
- **Description**: Removes Meet Now button from taskbar.

## Details

- Removes the Meet Now ( Skype Meet Now ) button from the Windows taskbar. This eliminates the quick-access button for starting instant video meetings, providing a cleaner taskbar appearance.

!!! tip "Recommended"
    This tweak is recommended.
