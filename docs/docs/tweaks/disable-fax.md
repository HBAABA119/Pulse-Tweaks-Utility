# Disable Fax Service

## Overview
- **ID/URL**: `disable-fax`
- **Description**: Disables Fax service for better performance.

## Details

- Disables the Windows Fax and Scan service. This legacy service is rarely used in modern environments. Disabling it frees up system resources and eliminates a potential security vector.

!!! tip "Recommended"
    This tweak is recommended.
