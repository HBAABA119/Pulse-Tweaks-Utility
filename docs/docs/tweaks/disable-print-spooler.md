# Disable Print Spooler

## Overview
- **ID/URL**: `disable-print-spooler`
- **Description**: Disables Print Spooler service for better performance.

## Details

- Disables the Windows Print Spooler service. **Warning:** This will prevent printing. Only use this if you don't need to print from this computer. This eliminates a common security vulnerability and frees up system resources.
