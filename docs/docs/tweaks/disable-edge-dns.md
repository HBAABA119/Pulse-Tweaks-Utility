# Disable Edge DNS

## Overview
- **ID/URL**: `disable-edge-dns`
- **Description**: Disables Edge built-in DNS client.

## Details

- Disables Microsoft Edge's built-in DNS client (DNS-over-HTTPS). This forces Edge to use the system DNS settings instead of its own encrypted DNS resolver, ensuring consistent DNS behavior across all applications.

!!! tip "Recommended"
    This tweak is recommended.
