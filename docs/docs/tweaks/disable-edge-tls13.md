# Disable Edge TLS1.3

## Overview
- **ID/URL**: `disable-edge-tls13`
- **Description**: Disables Edge TLS1.3 for compatibility.

## Details

- Disables TLS 1.3 protocol in Microsoft Edge. TLS 1.3 is the latest security protocol but may cause compatibility issues with some older websites or network configurations. Disabling it forces Edge to use TLS 1.2 instead.
