# Disable Hibernate

## Overview
- **ID/URL**: `disable-hibernate`
- **Description**: Disables hibernate to save disk space.

## Details

- Disables Windows Hibernate feature and removes the hibernation file (hiberfil.sys). This frees up significant disk space equal to your RAM size. Sleep mode will still be available for quick resume.

!!! tip "Recommended"
    This tweak is recommended.
