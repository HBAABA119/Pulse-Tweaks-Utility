# AMD Radeon Enhanced Sync

## Overview
- **ID/URL**: `amd-radeon-enhanced-sync`
- **Description**: Enables AMD Radeon enhanced synchronization for smoother gaming.

## Details

- Enables AMD Radeon Enhanced Sync technology for smoother gaming. Enhanced Sync allows the GPU to render frames without being constrained by the display's refresh rate, providing smoother gameplay while reducing screen tearing. It intelligently allows frames to be displayed when they're ready, resulting in a more responsive gaming experience.
