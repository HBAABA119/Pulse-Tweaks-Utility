# DNS Cloudflare

## Overview
- **ID/URL**: `dns-cloudflare`
- **Description**: Sets DNS to Cloudflare for faster and more private browsing.

## Details

- Sets DNS to Cloudflare (1.1.1.1 / 1.0.0.1) for faster and more private browsing. Cloudflare's DNS resolver is one of the fastest available, with built-in privacy features that don't log your queries. It supports DNS-over-HTTPS for enhanced security.
